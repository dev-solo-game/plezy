# 全场景用户操作与端到端流程模拟

> 状态：评审验证稿
> 创建日期：2026-11-15
> 关联文档：[多端同步、离线协同与远程投播控制架构计划](account-sync-remote-plan.md)、[多端冲突分析及消解架构文档](sync-and-cast-conflict-analysis.md)

本文档按真实用户使用动线，完整模拟 **8 大类、16 个细分场景** 下的用户操作与系统底层流转，用于逐项核对产品体验是否符合预期。

---

## 场景 1：纯单机首次使用（无服务器、无电视，仅手机或电脑）

**用户目标**：刚装好 Plezy，没有部署任何服务器，先在手机或电脑上挂载夸克网盘 / SMB 并看片。

1. **打开 App**：无需登录任何账号，直接进入本地默认工作区首页。
2. **添加媒体源**：
   - 进入「媒体来源」→ 选择「夸克网盘」→ 手机扫码登录（或选择 SMB/WebDAV 填入地址密码）。
   - **目录过滤**：勾选想要入库的影视文件夹（写入 `includePaths`），或长按排除相册/网课目录（写入 `excludePaths`），避免杂项视频污染媒体库。
3. **扫描与刮削**：
   - 系统执行一次全盘遍历，记录夸克增量水位线 `quarkCheckpoint`；随后由刮削器请求 TMDB / Bangumi 匹配海报、简介与分类（电影/电视剧/动漫/综艺/纪录片）。
   - 未匹配到的冷门片进入「未匹配」分类，用户手动搜索匹配后，系统写入 `matchLocked = true` 与 `MatchOverrideRecord`。
4. **看片与离线下载**：
   - 点击播放（通过本机 `127.0.0.1` 串流代理注入 Cookie / 转换 SMB Range 流），支持设置片头片尾跳过时间。
   - 点击下载可将视频缓存在手机本地，地铁无网时在「下载」或媒体详情页直接离线播放，观看进度独立保存在 `WorkWatchStates`。

## 场景 2：家中新添一台电视（无服务器、免配对，TV 零配置）

**用户目标**：不想在电视上用遥控器输账号密码、不想配置 TMDB 代理、也不想让电视重扫一遍网盘。

1. **电视端操作**：
   - 在 Android TV 上安装并打开 Plezy，**不需要登录任何账号，不需要配置任何挂载，不需要输入配对码**。
   - 电视后台自动开启 UDP `48633` 局域网广播和 WS `48632` 监听。
2. **手机端操作**：
   - 手机连上家里同一个 Wi-Fi，打开 Plezy。
   - 手机在 1~3 秒内自动发现「客厅电视」，在设备列表或提示栏点击**「同步媒体库与设置到客厅电视」**（可勾选是否同时下发网盘/NAS 凭据）。
3. **系统自动流转**：
   - 手机通过局域网 WS 直连，将以下数据一次性打包推给电视：
     - 挂载配置（`mount_config`，含目录白名单/黑名单）及加密后的凭据（可选一键下发）；
     - 已刮削好的成品索引包（`MountCatalogSnapshot`，含手动匹配锁定记录和 `quarkCheckpoint` 扫描水位线）；
     - 现有的观看进度、已看集数与片头片尾规则（`WorkWatchStates`、`WorkSkip`）。
4. **最终结果**：
   - **几秒钟内**，电视首页立刻亮出完整的片名、分类、手动修正结果以及「继续观看」进度（全程 **0 次网盘列目录、0 次 TMDB API 元数据刮削请求**）。
   - **海报图片加载**：电视端显示海报时，仍需根据同步过来的海报 URL（或同步的 TMDB 图片镜像域名）请求图片资源并缓存到电视本地；若电视网络直连 `image.tmdb.org` 不通且同局域网有手机在线，可由手机局域网轻量转发/分享已缓存的海报图作为兜底。

## 场景 3：手机详情页「指定设备播放」的 3 种片源分支

**用户目标**：在手机上逛海报墙，点开某部电影或某集电视剧的详情页，想直接让「客厅电视」播放。

### 分支 3A：电视已有网盘/NAS 凭据（99% 日常场景）
1. 用户在手机某影片详情页看到 `[▶ 播放]` 旁边的 `[📺 在「客厅电视」播放]` 按钮（若有多台在线设备则弹出设备列表），点击播放。
2. 手机通过局域网 WS 发送 `playMedia`（携带作品信息、片头片尾规则、手机当前的续播位置 `startPositionMs`、`mountId + path` 以及兜底中继 URL）。
3. 电视校验本机已存在该 `mountId` 且凭据有效 → **电视直接用自己的 Quark/SMB 驱动读取原片起播**。
4. **体验结果**：手机随后可以直接锁屏、关机甚至出门，电视继续流畅播放 4K 原盘，不消耗手机任何电量和流量。

### 分支 3B：电视还没配置该网盘/NAS 凭据（临时快速投播）
1. 用户新挂载了一个网盘或在手机上刚配了一个临时 WebDAV，还没同步给电视，直接在详情页点「在电视上播放」。
2. 电视收到 `playMedia`，发现本机没有该 `mountId` 的可用凭据 → 自动无缝回退拉取 `lanRelayFallback.videoStreamUrl`（`http://<手机IP>:<端口>/cast/<一次性Token>/video.mkv`）。
3. 手机内置串流代理负责向网盘拿流并转发 HTTP Range 给电视，手机自动挂起前台保活通知防止锁屏断流；同时界面温和提示「电视尚未授权此网盘，可点击同步凭据让电视直接播放」。

### 分支 3C：投播手机本地离线下载 / 手机本地文件夹里的视频
1. 手机在高铁上缓存了一部电影，回家后点开这部离线影片的详情页，点击「在电视上播放」。
2. 电视本机不可能有手机私有目录里的文件 → 自动通过 `lanRelayFallback` 从手机局域网串流代理直接拉流播放。
3. 手机端自动开启 Foreground Service 保活（持 WakeLock / Wi-Fi Lock）；播放期间电视通过 `syncState` 将进度实时回传给手机，两边 `WorkWatchStates` 同步更新。

## 场景 4：播放过程中的实时进度查看、远程操控与「接力播放」

**用户目标**：电视放片后，在手机上能随时看到播到哪了、远程快进/拖动进度、切音轨字幕、调片头片尾，甚至把画面接回手机看。

1. **实时感知（打开即见）**：
   - 电视播放期间，UDP `48633` 信标实时广播摘要；手机一打开 App，首页底栏在 1~3 秒内自动浮现 **Mini Cast Bar**（「客厅电视 · 正在播放《三体》S01E03」及实时进度条）。
2. **详情页动态变形**：
   - 如果用户在手机上点开《三体》详情页，系统发现电视正在播它，详情页顶部自动变为**「📺 正在客厅电视播放」控制卡片**（内置可拖动进度条、`⏪ -10s`、`⏯ 暂停`、`⏩ +10s`、`⏭ 下一集`、`💬 音轨/字幕`、`✂️ 片头片尾`、`📱 接力到本机`）。
3. **丝滑拖动进度条（无回弹）**：
   - 正常播放时，电视每 3 秒发一次位置心跳，手机按 60fps 本地线性插值渲染进度条。
   - 用户手指拖动手机进度条到 `25:00` 松手 → 手机发送 `seekTo(1500000, requestId)` 并激活 `Pending Seek Guard` 乐观锁定显示 `25:00`，忽略在途旧心跳 → 待电视跳转完成回推带同一 `requestId` 的 `syncState` 后恢复插值。**进度条丝滑跟手、绝不跳回**。
4. **实时调片头片尾 / 切音轨字幕**：
   - 在手机控制面板切换「英语音轨」或「中英双字」，电视播放器立即生效并回传最新选中态。
   - 在手机上修改该剧片头结束时间，电视播放器进度条上的蓝色竖条标记实时移动，下一集立即按新规则跳过。
5. **误触防打断保护**：
   - 如果电视正在放《三体》，用户在手机上逛到《奥本海默》误点了「在客厅电视播放」，手机弹窗提示：「客厅电视正在播放《三体》，是否切换播放《奥本海默》？」，确认后才切换。
6. **接力回手机播放（去卧室/洗手间）**：
   - 用户点击 **`[📱 接力到本机播放]`** → 手机发送 `pullPlaybackToController` → 电视立即暂停并保存最新毫秒位置返回给手机 → 手机直接从该毫秒数无缝续播。

## 场景 5：多端挂载与扫描刮削冲突边界场景

### 5A：同步前，手机和电视已经各自独立扫码挂载了同一个夸克账号
1. 手机先扫码挂了夸克（生成 `UUID_A`），电视之前也独立扫码挂了同一个夸克根目录（生成 `UUID_B`）。
2. 两端在局域网或云端同步相遇，比对发现两者的确定性源指纹 `canonicalKey` 均为 `quark:<uid>:<rootFolderId>`。
3. **系统自动归并**：保留权威 `mountId`（如 `UUID_A`），将电视的 `UUID_B` 文件和本地 Cookie 凭据原地迁移绑定到 `UUID_A` 上。**结果：不会出现双份文件版本，投播也能 100% 命中电视直连。**

### 5B：PC 配了代理刮削成功，电视没配代理刮削失败
1. PC 端配好 TMDB 代理将全库刮削成功（`matched`），并手动修正了几部冷门片（`matchLocked = true`）。
2. 电视端某天手动点了刷新，新扫到一部片但因为电视连不上 TMDB 标成了 `unmatched`；或者旧版本状态在同步时相遇。
3. **系统裁决**：严格执行**状态单调升级法则**（`matchLocked > matched > unmatched > pending`），电视的 `unmatched` 绝不会冲掉 PC 已经刮削好的 `matched` 和手动锁定结果。

### 5C：新转存剧集更新（追剧秒级上新）
1. 用户用手机往夸克网盘转存了《庆余年》最新一集，打开手机 Plezy 点一下刷新（或启动自动增量）。
2. 手机调用夸克增量接口（1 次请求，约 0.1 秒）发现新文件并完成刮削，生成 `MountCatalogDelta`（含新的 `quarkCheckpoint` 水位线）。
3. 手机通过局域网（或云服务器）将增量推给电视 → 电视直接入库出现新集数，并同步更新了本机的 `quarkCheckpoint` 水位线，**电视端不需要自己再去扫网盘或调用 TMDB API 重新刮削匹配**（仅在展示剧照/海报时按需下载图片）。

### 5D：跨挂载海报与移除挂载清理
1. 某剧第 1~10 集在夸克，第 11~20 集在家里 SMB（且 SMB 目录里有本地 `poster.jpg`）。
2. 同步给手机带出门后（手机此时连不上家里 SMB）：手机自动回退使用 `LibraryItems` 上保存的 TMDB 远程海报 URL，**海报不会裂图**。
3. 后来用户在设置里移除了家里 SMB 挂载：`pruneEmptyTitles()` 级联清理掉底下无视频支撑的第 11~20 集空条目，但第 1~10 集正常保留，且第 11~20 集在 `WorkWatchStates` 中的已看记录永久保留不丢失。

## 场景 6：纯离线外出 & 回家局域网自动同步（无服务器模式）

1. **外出无网**：用户在高铁/飞机上用手机看提前下载好的离线电影/剧集（看完了第 2、3 集），离线观看状态写入本机 `WorkWatchStates` 并记入 `SyncOutbox`。
2. **回家入网**：回到家手机连上 Wi-Fi，电视开机处于同一局域网。
3. **自动同步**：手机与电视通过 UDP 发现并自动建立轻量 WS 同步握手，交换水位向量 `PeerSyncWatermark`，发现手机有更新的 `work_watch` 记录 → 手机通过局域网直接将增量推给电视。
4. **结果**：全程**零服务器**，电视首页「继续观看」自动变为第 4 集，已看集数同步更新。

## 场景 7：部署自托管 Go 服务器后的跨网 / 异地协同

### 7A：启用服务器 & 新设备登录
1. 用户在 NAS/VPS 上启动自托管 Go 账号服务，手机登录账号，点击「导入本机已有片库、挂载与观看状态」完成上云。
2. 书房电脑或新电视安装 Plezy，电视用手机扫码快捷登录同一账号 → **无需找老设备扫码移交解密密钥**，登录同一账号后直接从服务器拉取挂载配置、刮削索引快照、手动锁定规则与全部历史观看状态。

### 7B：同在家里局域网时（即使已登录服务器）
1. 手机和电视都登录了同一个服务器账号，且此刻都在家里同一 Wi-Fi 下。
2. 手机通过 UDP 发现电视 IP 可达，按 `deviceId` 与服务器设备列表自动归并去重。
3. 手机点播电视、拖动进度条、手机本地视频中继串流、甚至几 MB 的刮削索引包传输，**全部优先直接走局域网连接**，延迟毫秒级，不消耗服务器带宽。

### 7C：出门在外（手机 5G vs 家里电视）
1. **智能选源防报错**：手机在户外 5G 下点开一部同时存在于「家里 SMB」和「夸克网盘」的电影点播放，系统探测内网 SMB 不可达，**自动跳过 SMB 版本直接起播夸克网盘版本**。
2. **异地同步与远程控制**：手机在外面看完 2 集，变更通过 HTTPS/WSS 实时同步到服务器；若家里电视开着，手机也能在设备列表里看到家里电视正在播什么、甚至异地通过服务器 WSS 中继控制家里电视播放或暂停。
3. **服务器宕机降级**：若家里 NAS 断电导致自托管服务器暂时不可达，手机与电视无缝退回本地工作区与局域网 P2P 模式，一切功能不受阻断；服务器恢复后自动补推 `SyncOutbox` 并通过全局 `(opId, updatedAt)` 幂等去重，绝不重复累加播放次数。

## 场景 8：多用户同 Wi-Fi 边界

1. **室友/家人使用不同服务器账号，同连一个家庭 Wi-Fi**：
   - 手机 A 登录账号 A，电脑 B 登录账号 B。
   - **数据严格隔离**：后台 P2P 同步检查到双方 `syncScopeKey`（`accountKey`）不同，**绝不互相同步挂载、片库和观看进度**。
   - **投播边界**：如果客厅电视未登录任何账号（公共模式），账号 A 和账号 B 都可以发现并投播客厅电视（且有播放中切换确认防误触）。
